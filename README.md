# The Agent Obstacle Course

A one time census of 5,000 of the world's most popular websites, measuring what stops a well behaved, honestly identified AI agent from simply reading them. Bot walls, JavaScript only pages, identity discrimination, and login walls, each detected mechanically and traceable to saved evidence. No AI judging, no cost, the whole scan runs once on GitHub Actions.

## Why

Everyone benchmarks AI agents. Nobody benchmarks the websites they must operate on. This study asks the inverse question, what fraction of the popular web can a non browser agent actually read, and what stops it on the rest?

## One time nature

The census runs exactly once. There is no schedule, no cron, no repeated crawling. The workflow only fires on a deliberate manual dispatch, and a shard is re-run only after an infrastructure failure on our side.

## Politeness commitments

- Every request carries an honest user agent naming this project, with a contact email, or a From header carrying the same email on the one stock browser comparison fetch.
- robots.txt is fetched first and honored. If it disallows the homepage, the site is not fetched further and is recorded as a declared exclusion, never as broken.
- At most 6 top level fetches per site, at least 2 seconds apart, 15 second timeout, one retry only after a network error, never after an HTTP error.
- A bot wall is a result, never a challenge to defeat. No form submission, no path probing beyond robots.txt and llms.txt.
- Any site owner can be excluded on request at asish-singh@x-b-e.com.

## How to reproduce

1. Install dependencies. `pip install requests tldextract playwright` then `playwright install chromium`.
2. Build the site list. `python3 -m src.build_sites` (downloads the Tranco list, the list ID lands in config/tranco-list-id.txt).
3. Run the tests. `python3 -m unittest discover -s tests`.
4. Pilot. Dispatch `.github/workflows/census.yml` with pilot set to true, which scans 50 sites and commits the evidence to data/pilot for hand review.
5. Census. Dispatch the same workflow with pilot set to false. Twenty shard jobs scan 250 sites each, then an aggregator writes data/census.csv and REPORT.md in a single commit.
